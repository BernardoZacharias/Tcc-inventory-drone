# Gestock Drone Agent — marcos 1 e 2 (vídeo e leitura de QR)
#
#   pip install -r requirements.txt
#
# ─────────────────────────────────────────────────────────────
# POR QUE O OPENCV ESTÁ TRAVADO ABAIXO DA 5.0
#
# Os wheels pré-compilados do opencv-python 5.0.x quebram com
# "illegal hardware instruction (core dumped)" — SIGILL — em várias
# CPUs, no momento em que o VideoCapture inicializa o backend FFmpeg.
# Não é erro de Python: é o binário nativo executando instrução que o
# processador não tem.
#
# A série 4.x é estável e tem exatamente as mesmas APIs que usamos.
# Só suba para a 5.x quando testar que o vídeo abre na sua máquina.
# ─────────────────────────────────────────────────────────────
opencv-python>=4.9,<5
numpy>=1.26,<3

# Leitura de QR. O pyzbar depende da biblioteca nativa ZBar:
#   Windows: já vem junto no pacote (não precisa instalar nada)
#   Linux:   sudo apt install libzbar0   /   sudo pacman -S zbar
#   macOS:   brew install zbar
pyzbar>=0.1.9

# Desenha um QR de verdade na fonte sintética. Usado nos testes de
# ponta a ponta e para demonstrar o Agent sem drone e sem câmera.
#
# Tem que ser qrcode[pil]: sem o Pillow o qrcode instala, importa e
# falha só na hora de gerar a imagem. A fonte sintética então desenha
# um retângulo no lugar do QR e a leitura fica em zero, parecendo
# defeito do leitor.
qrcode[pil]>=7.4
